# StyleHub – Fashion & Apparel E-Commerce Website

StyleHub is a modern, responsive, frontend-only fashion and apparel e-commerce website developed as an internship project.

The website simulates a complete online shopping experience for Men, Women, and Kids collections, including product discovery, filtering, product details, cart management, wishlist, checkout, simulated payment, order confirmation, and order tracking.

All prices are presented in Indian Rupees (₹ / INR).

## 📌 Project Overview

StyleHub is a frontend-only fashion and apparel e-commerce website created to simulate a complete online shopping experience for an Indian audience.

The project provides clothing collections for:

- Men
- Women
- Kids

It demonstrates how a complete interactive e-commerce workflow can be implemented using HTML5, CSS3, and vanilla JavaScript without requiring a backend or database.

Client-side persistence is implemented using browser LocalStorage.

---

## 🎯 Project Objectives

The main objectives of StyleHub are:

- Develop a modern fashion e-commerce frontend.
- Create a clean and user-friendly shopping experience.
- Implement interactive e-commerce functionality using JavaScript.
- Practice DOM manipulation and event handling.
- Implement responsive web design using CSS3.
- Use JavaScript arrays and objects for frontend application data.
- Use LocalStorage for client-side persistence.
- Build a complete shopping workflow without a backend or database.

## 💾 Data & Storage

StyleHub does not use a backend, database, or external API.

Product and application data are handled using JavaScript arrays and objects inside `script.js`.

LocalStorage is used to persist relevant client-side state between page loads, including cart contents, wishlist items, orders, saved addresses, and user preferences.

---

## 🔐 Authentication & Payment

Authentication and payment functionality are simulated for demonstration purposes.

No real credentials or payment information are transmitted.
